The governing point

The two founders live in the van and on the phone. The OS has to work between sites: log the call they just took, take the client update, triage the sales blocker, see the next site — in seconds, not at a desk. Monday Command still holds the quarter. The phone holds the day.

01   What this OS is

Five desk modules. One phone. The phone is the workstation.

The intern still sources and qualifies. Michael still delivers. Carys still chases cash. Founders are between sites most of the day — inbound calls, client updates, sales blockers. Desk Command is Monday and the rare sit-down. Everything else is a three-card phone strip plus a 20-second log form.

In

The OS does

Give founders a phone they can run between sites, and a Monday Command for the quarter. Capture every founder call and client update on the record. Progress tenders through two document gates. Surface blockers with an owner. Show install load, crew, and materials for 90 days. Translate the pipeline into a forecast.

Out

The OS does not

Replace Xero, run VAT, source leads for the founders, auto-close deals, or become a chief-of-staff company OS. Academy and tours stay off this spine.

02   Stack and anti-goals

Buy the ledger, compose the OS, build only the agent

Do not start a custom app. IT-immature teams fail on auth, backups, and the intern becoming a bottleneck. Founders live on the phone. The record is Airtable. Xero is for when they sit down. WhatsApp and voicemail are capture, never the system of record.

05   Handoffs, WIP, and path rules

Three handoffs. Two WIP caps. A tender document path. A blocker rule

Handoff 1 — Qualified → founders

Intern may set Stage to Qualified only when all of these are true: Real site, Budget, Intent, Courts (n), Why qualified, Suggested visit window, Drive folder, Handoff ready. Close view ignores the row until Handoff ready. Default Owner then becomes Founder A or B by key-account map, else round-robin.

Handoff 2 — Booked → Michael

Founder sets Stage to Booked and Booked date. Automation or Carys creates: Project at Pre-contract, InvoiceEvent Type = Deposit, a MaterialLine for Court kit (MANZA) at Not ordered, Drive project folder. Owner = Michael. Next actions: confirm deposit in Xero, set install window, assign crew, order kit. The project appears on Install 90 as soon as a window exists.

Handoff 3 — Complete → Paul

Michael cannot set Complete until Photo set, Snag list, and Founder sign-off. Then: update Account Deployed and Padel-Craft deployed; set Last install quality; create MaintenanceContract at Status = Prospect (or Active if they signed on handover). Paul’s Aftercare view is the installed base, including not-on-plan.

Direct vs tender document path

Direct

Quote path

Site visit → proposal (model, budget, timeline) → verbal → booked deposit. Tender fields stay blank. Typical leisure club and private operator.

Tender / procurement

Two document gates

Initial contact → Qualifying → Bid/no-bid (founder, before Carys drafts) → Initial document out (pack sent + date) → wait / clarification → Secondary document out when the buyer issues stage 2 or BAFO → Award pending → Won maps to Verbal then Booked. A tender with no next deadline is a leak. Single-stage RFTs leave Secondary pack due blank.

Weekly pipeline meeting · 30 to 45 minutes

Same slot each week. Founders + Michael + intern (Carys if cash or a pack is due). Run on Command only.

  1. Sold. Last quarter, last week, this week, projected this quarter. One glance at whether the quarter is alive.
  2. Forecast. Weighted next quarter and 12 months. Date or park every undated leak. Recalibrate weights only after week 8.
  3. Tenders. Every pack due in 14 days. Bid/no-bid decisions. Initial document out and secondary document out with owners.
  4. Blockers. Red first. Assign or clear. Nothing stays as a note.
  5. Road log. Unlogged founder calls this week (Activity Kind = Founder call / Client inbound vs their actual week). If the inbox is backing up, the OS is not on the phone yet.
  6. Install 90. How each live install is going. Crew coverage and materials ordered-or-not for the next 90 days. Unresourced windows become Crew or Material blockers before the meeting ends.

When a WIP limit is hit the answer is close, lose, or park — not add. That is what keeps founders out of firefighting.

09   Lead-generation agent

Build this, not a prettier dashboard

The intern’s product is outbound at scale into Airtable. The dashboard is Interfaces.

  • Read Account sorted by Priority, then Headroom. Skip Low unless a founder tagged Owner.
  • Personalise outreach. Log every send and reply as Activity. Outcome must be one of the select values.
  • Stop at Conversation. A human ticks Real site / Budget / Intent and Handoff ready.
  • Never set Stage to Booked, never create a Project, never email founders a raw name.
  • If the agent cannot write a clean Activity row, it is not in production.

Keep the agent stateless against Account. No separate prospect database. The scarce output is six genuinely qualified opportunities a week, not two hundred emails.

10   Success bar, end of 90 days

The phone holds the day or the OS has failed

  • Founders run the day from Between sites: next site, calls to return, own red blockers.
  • A founder call or client update is an Activity row within the hour (typed or via OS inbox). Not Sunday batching. Not WhatsApp-as-record.
  • Raise blocker? on the phone form creates a Blocker. Sales blockers from calls are visible on Command Monday.
  • Weekly meeting uses desk Command only. No side lists.
  • Every live tender has a Tender stage and a next document deadline, or it is a leak.
  • Initial document out and secondary document out are dates on the record, not emails.
  • Open blockers have an owner, a due date, and a next move. Red ones have Founder action ticked.
  • Every project in the next 90 days shows crew coverage and whether kit is ordered.
  • Sold strip shows last quarter, last week, this week, projected this quarter from Booked date.
  • Next quarter and 12-month weighted forecasts exist; undated Expected close is visible as a leak.
  • Founders do not source leads. Quality pack is in use on new Completes.
